# OCRCaptureTool

OCRCaptureTool 是一个用于区域截图、OCR 识别及相关屏幕辅助功能的工具。

项目包含两个版本：

| 版本 | 说明 |
| --- | --- |
| **Full** | 完整版，包含完整功能 |
| **Lite** | 精简版，体积和依赖更轻，保留主要功能 |

## 工程目录

```text
OCRCaptureTool/
├── Full/    # 完整版
└── Lite/    # 精简版
```

两个版本分别独立维护，具体使用方法和版本说明请查看对应目录中的 README。

## 选择版本

需要完整功能：

```text
Full/
```

需要更精简的版本：

```text
Lite/
```
